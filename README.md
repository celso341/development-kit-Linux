## :bookmark: Sobre
Um conjunto de scripts e configurações desenvolvidos para agilizar a instalação de ambientes de desenvolvimento em distribuições Linux (Fedora/Ubuntu).

## 🚀 Tecnologias usadas
- [Shell Script](https://www.shellscript.sh/)
- [Linux (Fedora/Ubuntu)](https://getfedora.org/)
- [Git](https://git-scm.com/)

## :fire: Como usar
1. Clone o repositório: `$ git clone https://github.com/celso341/development-kit-Linux.git`
2. Dê permissão de execução: `$ chmod +x install.sh`
3. Execute: `$ ./install.sh`
